# Dorm Dash

## Overview
This is a Java and MySQL application for Dorm Dash.  
This is the program that helps manage inventory, orders, library requests, and weekly reports.

## Project Structure
This is the app folder which contains the main entry point of the program.

This is the bll folder which contains the business logic classes.

This is the dal folder which contains the data access classes.

This is the models folder which contains the model classes.

This is the utils folder which contains helper and configuration classes.

This is the Database folder which contains the SQL scripts.

This is the Design folder which will contain UML diagrams, ER diagrams, activity diagrams, and sequence diagrams.

## Run Steps
This is step 1: run the SQL script in the Database folder.

This is step 2: make sure MySQL is running.

This is step 3: update the username and password in DbConfig.java.

This is step 4: open the project in VS Code.

This is step 5: compile and run Main.java.
