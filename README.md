Dorm Dash Run Instructions
Open the project in Visual Studio Code
Open the file:
app/Main.java
Ensure MySQL is running locally and the DormDash database has been created by executing:
Database/DormDash.sql
Verify database credentials in:
utils/DBConfig.java
match your local MySQL username/password.
Click Run in VS Code while inside Main.java
The Dorm Dash menu will appear in the terminal
Follow the prompts to test each workflow:
Inventory Entry
Dorm Dash Order
Library Pickup / Return
Weekly Manager Report 
Running Unit Tests
Open any file in the test folder
Click Run Test in VS Code
 OR use the Testing sidebar to run all tests
